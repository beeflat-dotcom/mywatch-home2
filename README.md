# Bee Transceiver distribution site

Published as the `gh-pages` branch of `beeflat-dotcom/mywatch-home2`.

Once GitHub Pages is enabled in repository settings (Deploy from a branch, `gh-pages`, `/(root)`), the URL is:

https://beeflat-dotcom.github.io/mywatch-home2/

The updater manifest is https://beeflat-dotcom.github.io/mywatch-home2/latest.json .

Release automation updates latest.json **only after** a signed APK has been published to GitHub Releases. Do not edit versionCode or SHA256 by hand unless validating a manually signed release.

Never commit Android keystores, private keys, API tokens or device pairing tokens to this branch.
